# Lumina Study — Инструкции для Gemini CLI

Этот файл содержит контекст и рекомендации для работы с проектом **Lumina Study**.

## Обзор проекта
**Lumina Study** — это эстетичное и поддерживающее веб-приложение для помощи школьникам (целевая аудитория — 8 класс) в учебе. Оно объединяет в себе ИИ-тьютора, планировщик задач, таймер фокуса и расписание уроков.

### Основные технологии
- **Frontend:** React 19 (TypeScript), Vite
- **Стилизация:** Tailwind CSS 4, Framer Motion (анимации)
- **ИИ:** Google Gemini API (`@google/genai`), модель `gemini-3-flash-preview`
- **Иконки:** Lucide React
- **Хранение данных:** LocalStorage (для задач, профиля и расписания)

## Архитектура проекта
- `src/App.tsx`: Главный компонент, управляющий навигацией и отображением всех представлений (Dashboard, Planner, Tutor, Focus, Tips, Profile).
- `src/services/gemini.ts`: Сервис для взаимодействия с Gemini API. Содержит системные инструкции для персонажа Lumina.
- `src/types.ts`: Определения типов TypeScript.
- `src/constants.ts`: Константы, моковые данные и начальные конфигурации.
- `src/index.css`: Глобальные стили и переменные темы.

## Команды и запуск
- `npm install` — установка зависимостей.
- `npm run dev` — запуск сервера для разработки на порту 3000.
- `npm run build` — сборка проекта для продакшена.
- `npm run lint` — проверка типов TypeScript.

**Конфигурация:**
Для работы ИИ необходимо установить переменную окружения `GEMINI_API_KEY` в файле `.env.local`.

## Конвенции разработки

### Персонаж Lumina
Lumina — это не просто чат-бот, а заботливый и дружелюбный репетитор. 
- **Тон:** Воодушевляющий, добрый, использует эмодзи (✨, 💖, 📚).
- **Подход:** Не дает готовых ответов сразу, а помогает ученику найти их самостоятельно, объясняя шаги.
- **Язык:** Русский, понятный восьмикласснику.

### Стилизация и UI
- Приложение использует мягкую "шалфейную" тему (`sage`).
- Активно используется стекломорфизм (`glass-panel`) и плавные анимации через Framer Motion.
- UI должен оставаться "чистым" и минималистичным, ориентированным на продуктивность без стресса.

### Работа с состоянием
- Состояние приложения хранится локально в `App.tsx` и синхронизируется с `localStorage`.
- При добавлении новых функций важно сохранять эту модель персистентности.

## Инструкции для Gemini CLI
- При внесении изменений в UI придерживайтесь установленной цветовой схемы (`sage`, `paper`, `dark-card`).
- При модификации логики ИИ-тьютора сверяйтесь с `SYSTEM_INSTRUCTION` в `src/services/gemini.ts`.
- Всегда проверяйте типы (`npm run lint`) после правок в коде.
- Отвечайте на русском языке, согласно глобальным настройкам.
